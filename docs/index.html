install

Needs Python 3.11+ and uv.

uv tool install git+https://github.com/lounesart/sysreport

usage

sysreport            # the table
sysreport --explain  # what's wrong and how to fix it
sysreport --fix      # fix things one command at a time
sysreport --json     # JSON for scripts

Exit codes: 0 ok, 1 warnings, 2 failures.

--fix

For each problem it explains what's going on, then shows the fix commands one at a time with a note on what each one does. You choose run, skip or quit every time. Skip is the default. Afterwards it re-runs the check so you can see if it worked.

~ ❯ sysreport --fix
Step 2/2 [change] (needs your password)
  $ sudo pacman -Syu
  What: Syncs package databases (-y) and upgrades every installed package (-u).
  Why:  This is the only supported way to update Arch.
  Run this command? [r/s/q] (s): █

It won't allow USB devices or touch kernel boot parameters for you. For those it just explains the steps.
